# Requirements

- F-01 (must, gate): The agent protocol is generally available in a vendor-supported release.
- F-02 (must): Model routing with fallback between providers.
- F-03 (should): Prompt and skills management.
- P-01 (must, gate): Every package component is supported on the target Kubernetes platform.
- P-02 (must, gate): Install, upgrade and licence validation work offline.
- P-03 (must, gate): Each site keeps working when the control plane is lost.
- S-01 (must, gate): Vendor support is available in the customer's country.
- S-02 (must, gate): Licensing and entitlement are clear (which SKU covers what).
- C-01 (must): Predictable pricing at 20 million requests per month.
- C-02 (should): A usable free or development tier.
